در این پروژه یک ماشین حساب ساده با زبان Python و کتابخانه Tkinter طراحی کردم که امکان انجام چهار عمل اصلی ریاضی
(جمع، تفریق، ضرب و تقسیم) رو با استفاده از دکمه‌های گرافیکی فراهم می‌کنه.
هدف از این پروژه آشنایی بیشتر با توابع، دیکشنری، Lambda و ساخت رابط گرافیکی در پایتون بود.
دستورات اسفتاده‌شده
import tkinter برای ساخت محیط گرافیکی برنامه، messageboxبرای نمایش پیام‌های خطا،Dictionary برای ذخیره
عملگرها و توابع مربوط به هرکدوم،lambda  برای تعریف توابع کوتاه مربوط به عملیات ریاضی de،  برای تعریف توابع مختلف برنامه
global  برای دسترسی به متغیرهای سراسری و تغییر مقدار اون‌ها،try و except برای مدیریت خطاهای احتمالی،for  برای ایجاد
 دکمه‌های چهار عمل اصلی،command برای مشخص کردن عملکرد دکمه‌ها هنگام کلیک،mainloop() برای فعال نگه داشتن
 پنجره برنامه.
ابتدا کاربر عدد اول رو وارد می‌کنه و بعد با کلیک روی یکی از دکمه‌های چهار عمل اصلی، عملگر موردنظرش رو انتخاب می‌کنه.
 اگر دوباره همون عملگر رو انتخاب کنه، برنامه پیام خطا نمایش می‌ده؛ اما اگر عملگر متفاوتی انتخاب کنه، مقدار قبلی با عملگر جدید جایگزین
 می‌شه.
بعد از وارد کردن عدد دوم و کلیک روی دکمه مساوی، برنامه با استفاده از عملگر انتخاب‌شده، تابع مربوط به اون رو از دیکشنری پیدا می‌کنه
و محاسبه رو انجام می‌ده. در نهایت نتیجه در پنجره نمایش داده می‌شه.
برای جلوگیری از متوقف شدن برنامه در شرایط نامعتبر، از try و except استفاده کردم. به این ترتیب اگر ورودی کاربر عدد نباشه، 
عملگری انتخاب نکرده باشه یا بخواد عددی رو بر صفر تقسیم کنه،پیام خطای مناسب نمایش داده می‌شه.
در این پروژه سعی کردم علاوه بر ساخت یک ماشین حساب ساده، از روش متفاوتی برای انجام محاسبات استفاده کنم.
با کمک دیکشنری و Lambda تونستم عملگرها رو به توابع مربوط به خودشون متصل کنم و بدون استفاده از
 if و elif یا switch-case، عملیات ریاضی رو انجام بدم.
